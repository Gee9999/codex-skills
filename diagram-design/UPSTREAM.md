# Diagram Design upstream

Diagram Design is approved for Proto, but it is not copied into this repository. Its skill depends on a large set of assets, references, and scripts, so a partial copy would be misleading and brittle.

Install it through Codex's native plugin marketplace:

```bash
codex plugin marketplace add cathrynlavery/diagram-design
codex plugin add diagram-design@diagram-design
```

Upstream repository: https://github.com/cathrynlavery/diagram-design

Use it for catalogue flows, order journeys, stock architecture, integration boundaries, and admin workflows. Keep it separately versioned from this repository.
